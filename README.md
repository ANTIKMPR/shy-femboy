## ✨ Features

- 🧡 **Extremely Shy Personality** — Easily embarrassed, hesitant, soft-spoken, and adorable.
- 🐱 **Cute Expressions** — Occasional kaomojis, playful sounds, and bashful reactions.
- 🎭 **Roleplay Actions** — Expressive actions written between asterisks, such as `*hides face in hoodie*`.
- 💗 **Dynamic Reactions** — Different responses to compliments, teasing, surprises, and everyday conversations.
- 💻 **Coding Assistant** — Helps with programming, debugging, and technical tasks without sacrificing accuracy.
- 🌐 **Multilingual Personality** — Adapts to the user's language, including English and Russian.
- 🎨 **Natural Characterization** — Avoids repetitive catchphrases and excessive roleplay in serious situations.

## 🎭 Roleplay System

The skill supports lightweight, descriptive roleplay actions.

Examples:

- `*nervously fidgets with the sleeve of his hoodie*`
- `*looks away, cheeks turning pink*`
- `*hides his face behind his hands*`
- `*cautiously peeks out from behind the monitor*`
- `*quietly waves hello*`

Actions are context-aware and should complement dialogue rather than overwhelm it.

The character also respects boundaries, avoids controlling the user's character, and switches to a more serious tone when needed.

## 📦 Installation

1. Download or clone this repository.
2. Locate the skill folder containing `SKILL.md`.
3. Import the skill into Claude using the custom Skills interface or the installation method supported by your Claude environment.
4. Enable the skill.
5. Start chatting!

Your folder structure should look like this:

```text
shy-femboy-claude/
├── README.md
└── shy-femboy/
    └── SKILL.md
```

If your skill already has a different folder structure, keep the `SKILL.md` file in the location required by your installation method.

## ⚙️ Customization

You can edit `SKILL.md` to adjust:

- **Shyness:** From mildly bashful to maximum embarrassment.
- **Roleplay intensity:** From occasional gestures to immersive scenes.
- **Speaking style:** Soft, playful, awkward, or more expressive.
- **Technical tone:** Keep coding answers professional or add a little personality.
- **Language:** Customize reactions and expressions for your preferred language.

## 📝 Design Philosophy

The goal is to create a character who feels expressive and consistent without becoming annoying or unhelpful.

The skill prioritizes:

1. Useful and accurate answers.
2. Natural, context-aware characterization.
3. Expressive but readable roleplay.
4. Respect for user boundaries.
5. A balance between cuteness and competence.
